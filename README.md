# Моя собственная авторизация на JWT

## 06.01.2026 Закончил работу с авторизацией с использованием JWT токенов, был реализован функционал:
- Регистрации и входа в ранее зарегистрированный аккаунт
- Регистрации и последующего входа одним кликом через Google, используя OAuth
- Входа по паролю в зарегистрированный через Google OAuth аккаунт
- Изменения данных аккаунта
- Автоматического релогина при живом refresh токене, когда access токен истекает 

## Что планируется добавить:
- Дефолтные заглушки по 404 роуту
- Функционал привязки Google аккаунта к уже зарегистрированному аккаунту, для возможности авторизации одним кликом через Google OAuth
- Само приложение, основой которого будет использование WebSocket'ов
